Spear is a universal WordPress theme for business, agency, SaaS, blog,
portfolio, and WooCommerce sites. It works with Gutenberg, Elementor,
Divi, Bricks, Beaver Builder, WPBakery, and Oxygen, and ships its own
native visual editor, Spear Editor, with optional AI-assisted page
generation (Spear AI).

== Description ==

Spear is the Free edition — it contains only the free feature set,
with locked "Get Spear Pro" cards shown in the Customizer for Pro
features. Pro functionality ships as a separate, fully-unlocked theme
package ("spear-pro"), not a license unlock of this theme. See
docs/architecture/ in the project root for the full product architecture,
including the Free/Pro package split, module system, and design system.

Spear Editor, the companion native visual editor, ships as a separate
plugin ("spear-editor") and works with any theme, including both Spear
and Spear Pro.

== Installation ==

1. Upload the `spear` directory to `/wp-content/themes/`.
2. Activate Spear through the “Themes” screen in wp-admin.
3. (Optional) Install the Spear Editor plugin for the native visual
   editor, AI generation, and design import tools.

== Frequently Asked Questions ==

= Is Spear Pro required to use this theme? =

No. Spear ships a complete, standalone free feature set. Locked
"Get Spear Pro" cards appear in the Customizer next to their free
counterparts as static marketing for the separate Spear Pro theme —
they are not a trial or a license unlock of this theme.

= Does Spear work with page builders? =

Yes. Spear includes Universal Editor API adapters for Gutenberg,
Elementor, Divi, Bricks, Beaver Builder, WPBakery, and Oxygen, plus its
own native visual editor, Spear Editor (a separate plugin).

= Where do I report a bug or request a feature? =

See docs/architecture/ in the project root for the theme's architecture
and module system before filing an issue.
