Spear is a universal block theme for business, agency, blog, portfolio, and WooCommerce sites.

== Description ==

Spear is a flexible, standalone block theme built on theme.json and the WordPress Site Editor. It gives you a clean starting point for many kinds of sites and works with the block editor and popular page builders.

Features:

* Block theme with theme.json design tokens and default block templates.
* Customizer settings for header (layout and width), footer (layout and copyright text), blog (excerpt length and post date), and WooCommerce (products per page and columns).
* Starter Sites screen under Appearance to import ready-made pages built from block patterns. Importing only creates new pages and never deletes existing content.
* Compatible with Gutenberg, Elementor, Divi, Bricks, Beaver Builder, WPBakery, and Oxygen.
* WooCommerce support.
* Translation ready.

== Installation ==

1. In wp-admin, go to Appearance > Themes > Add New > Upload Theme and choose the theme zip, or upload the `spear` directory to `/wp-content/themes/`.
2. Activate Spear through the Themes screen.
3. Customize header, footer, blog, and WooCommerce options under Appearance > Customize.
4. (Optional) Import a starter site under Appearance > Starter Sites.

== Frequently Asked Questions ==

= Does Spear work with page builders? =

Yes. Spear includes adapters for Gutenberg, Elementor, Divi, Bricks, Beaver Builder, WPBakery, and Oxygen. The builder plugins themselves are installed separately.

= Does Spear support WooCommerce? =

Yes. When WooCommerce is active, Spear adds options for products per page and shop columns in the Customizer.

= Does importing a starter site delete my content? =

No. It creates new pages and sets the first one as the front page. Existing content is left untouched.
